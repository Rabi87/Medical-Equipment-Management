# نظام إدارة شركة تجهيزات طبية

## نظرة عامة
نظام إدارة متكامل لشركة متخصصة في استيراد وبيع وصيانة الأجهزة الطبية، يربط بين المبيعات، المخزون، الصيانة، وتتبع أداء المندوبين.

## الميزات الرئيسية

### 1. إدارة المخزون
- إضافة/تعديل/حذف الأجهزة الطبية
- تتبع حالة الجهاز (في المخزون/مباع/تحت الصيانة)
- سجل حركات المخزون الكامل
- تنبيهات الحدود الدنيا والقصوى

### 2. إدارة الأعطال والصيانة
- تسجيل أعطال الأجهزة من قبل المندوبين أو المدير
- تعيين مندوب صيانة لكل عطل
- تتبع حالة العطل (قيد الانتظار/قيد الإصلاح/تم الإصلاح)
- سجل تفصيلي لكل عمليات الصيانة

### 3. إدارة المبيعات والمشافي
- ربط الأجهزة بالمشافي المشتراة لها
- تتبع المندوب المسؤول عن كل مشفى
- إدارة علاقات المندوبين مع المشافي

### 4. التقارير والإحصائيات
- بطاقة جهاز تفصيلية (تاريخ الشراء، الكفالة، المشتري، كل الأعطال)
- بطاقة مندوب (المشافي المغطاة، سجل الأعطال، الأداء)
- تقارير المخزون والتقادم
- أداء المندوبين (وقت الإصلاح المتوسط، عدد الأعطال)

### 5. سجل النظام
- تتبع كل العمليات (إنشاء، تعديل، حذف)
- تخزين البيانات القديمة والجديدة (JSON)
- تسجيل عنوان IP والتوقيت لكل عملية

### 6. إدارة المستخدمين
- 3 صلاحيات: مدير، مندوب صيانة، مسؤول مخزن
- تتبع آخر دخول وعنوان IP
- تشفير كلمات المرور (bcrypt)

## البنية التقنية

### التكنولوجيا المستخدمة
- **Backend**: PHP 7.4+
- **Database**: MySQL 8.0
- **Frontend**: HTML5, CSS3, JavaScript
- **Framework**: Bootstrap 5
- **Icons**: Font Awesome 6

### هيكل قاعدة البيانات
- `users`: إدارة المستخدمين والصلاحيات
- `devices`: أجهزة الطبية والمواصفات
- `hospitals`: المشافي وبيانات الاتصال
- `suppliers`: الموردين والشحنات
- `maintenance_logs`: سجلات الصيانة والأعطال
- `stock_movements`: حركات المخزون
- `minmax_settings`: إعدادات الحدود الدنيا/العليا
- `system_logs`: سجل النظام والشواذ

## الصلاحيات

### المدير (admin)
- الوصول الكامل لجميع الوظائف
- إدارة المستخدمين والمشافي والموردين
- عرض جميع التقارير وسجل النظام

### المندوب (rep)
- تسجيل أعطال جديدة للأجهزة في مشافيهم
- تحديث حالة الأعطال الموكلة لهم
- رؤية قائمة أجهزتهم وأعطالهم
- لا يمكنه تعديل بيانات المخزون أو المستخدمين

### مسؤول المخزن (storekeeper)
- إدارة إدخال/إخراج الأجهزة
- تعديل بيانات الأجهزة والمخزون
- لا يمكنه إدارة المستخدمين أو المشافي

## التثبيت والتشغيل

### الشرط المسبق
- Docker و Docker Compose مثبتين
- منفذ 8080 متاح

### خطوات التشغيل

```bash
# التنقل إلى مجلد المشروع
cd /home/rabi/Docker-Containers/php-mysql-docker

# تشغيل الحاويات
docker-compose up -d

# التحقق من تشغيل الخدمات
docker-compose ps
```

### الوصول إلى النظام
- **واجهة النظام**: http://localhost:8080/care-devices
- **صفحة الدخول**: http://localhost:8080/care-devices/login.php

### بيانات اختبار النظام

| الدور | اسم المستخدم | كلمة المرور |
|-------|--------------|-------------|
| مدير | admin | admin |
| مندوب | rep1 | rep1 |
| مخزن | store1 | store1 |
